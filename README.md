# XGEN Interactive Demo

图文交互小世界原型：Agent 辅助创作、角色视角探索、独立角色对话，以及个人资料与虚拟形象管理。

## 本地运行

需要 Node.js 22.13 或更高版本。

```sh
npm ci
cp .env.example .env.local
npm run dev
```

按 `.env.example` 配置自己的模型网关和 Supabase 服务。不要提交 `.env.local`，也不要在客户端暴露服务端密钥。未配置外部服务时，依赖模型、账号和云存储的功能不可用。

```sh
npm run build
npm start
```

数据库初始化文件位于 `supabase/migrations`，请在自己的项目中按时间顺序执行并检查访问权限。GitHub 登录需要另行配置 OAuth。公开作品发布默认关闭，不要未经权限及隐私验收直接开启。
