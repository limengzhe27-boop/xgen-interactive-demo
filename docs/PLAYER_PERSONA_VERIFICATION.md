# 虚构身份与世界入场 · 2026-09-06

## 当前范围

- 个人 Agent 页有独立、默认折叠的虚构身份档案：名称、背景、性格、外观、愿望能力，可显式保存，可按需生图。登录账号隔离，当前仍为本机存储，不是云账号档案；不从个人聊天或记忆自动填入。
- 创作者第三步定义是否开放自带身份、可代入角色、仅原角色能力／固定额外能力；Agent 可讨论并提出独立政策建议，用户确认才应用。角色删除或重排后，入场许可按编辑身份保留，不转给新角色。
- 体验者保留名字、性格、外观，代入创作者开放的剧情位置。关系、知识、目标、任务 ID 保留；自带背景和愿望能力不自动生效。独立确认后创建探索／角色会面快照，不修改原世界。
- 仅《离婚当天，前夫的死对头来接我》的苏晚、顾言舟默认开放示例入口；其他旧世界默认关闭。自建世界可手动开启。
- 适配快照不含账号 ID、真实记忆、自带背景与愿望能力；服务端检查适配角色和授权能力是否与政策一致。文字能力仍由模型依据世界规则解释，不是完整数值战斗／能力执行引擎，不宣称能杜绝所有语义绕过。
- 改名会同步替换新会话的叙事称呼，保留引用 ID；不复用被替代角色的人像。未生成形象时显示身份标识，不擅自展示另一张脸。开场复用场景图，后续按原生图间隔和缓存策略执行。
- 不允许把玩家适配后的私人会话当成原世界公开发布。公开世界只白名单保留创作者政策，公开发布开关仍关闭。
