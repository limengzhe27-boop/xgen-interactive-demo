# 第一人称与双版序章样本

## 入口

- `/prologue-comparison`：第一人称修仙20秒、瑜伽馆原版20秒、新版14秒，独立切换播放，无重新生成。
- `/?world=ascension-work-number`：固定沈砚身份，视频后直接开始互动。一个可体验身份与一名NPC，不把NPC当作第二个待选主角。
- 瑜伽馆世界默认仍为 `yoga-v2`；`yoga-v3` 是对比剪辑，结束点提前到教室内看消息，未替换原版更衣室开场。

## 媒体与连续性

- GPT原创封面：`public/assets/ascension-v1/cover.webp`。提示锚点：双眼第一人称、靛蓝破袖、左腕红绳、右手断剑、半开玉门、云海石桥、青铜巨钟、白发蒙面接引官。不是第三人称主角肖像。
- NPC形象与互动开场图从实际生成片段裁切/导出，保持同一演员、服装和场景，不另换脸。
- 公司网关 `kling-video-o1`，std模式，共四次10秒提交，两组首镜+基于已审尾帧的续镜；没有自动付费重试。
- 修仙原分镜“链条悬停、展示NPC腕锁”未被准确执行；实际是链缠红绳、NPC转身。已把原创样本前情与物理规则调整为强制拘束、未签契/未入门，而非假称玩家同意。可以消耗一次护身剑气斩断链条，不能强推入门。
- 瑜伽馆第二段后半出现摄影设备与手臂穿帮；剔除第二段4秒之后，只发布14秒对比剪辑。保留训练→停止训练→自愿拥吻→查看丈夫消息的顺序。没有用字幕声称拍到退入隔间。
- 无音轨，关键身份用内嵌中文字幕呈现，播放器明确标为无声字幕。旧版使用页面字幕。视频不是实时生成的后续互动。
