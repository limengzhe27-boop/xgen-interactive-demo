# 免费语音方案与实现边界 · 2026-09-07

当前基础版：系统听写指引 + 浏览器本地中文朗读。未调用付费语音 API，未录音；网页不能直接启动操作系统听写，用户需要使用键盘/系统入口。操作系统听写是否联网由系统设置决定。

只选择 SpeechSynthesisVoice.localService=true 的中文音色；无可用音色则说明限制，不静默使用远程音色。角色按稳定键选择音色，但数量取决于设备，不保证每个角色独一无二；同一角色跨设备也可能声音不同。支持单段语速/音色选择、停止、隐藏页面停止、卸载停止。不自动播放、不复制他人真实声音、不保存音频。

已接入个人助手回复和独立角色对话。统一 MessageTextarea 提供听写指引。世界探索正文、创作回复的分角色连续配音暂未接入。语速不等于可控情绪；本地系统朗读也不等于部署了下列开源神经模型。

## 开源候选（官方资料）

- [Kokoro-82M-v1.1-zh](https://huggingface.co/hexgrad/Kokoro-82M-v1.1-zh)：Apache-2.0；82M 参数，中英文；模型卡列出 103 个音色（含英文）。适合先做中文多音色小规模测试。模型卡当前没有托管推理供应商，不把公开演示当无限免费生产 API。
- [Qwen3-TTS](https://github.com/QwenLM/Qwen3-TTS)：1.7B CustomVoice 支持 9 个预设音色与指令式风格控制；VoiceDesign 支持按描述设计声音。相较单纯变速更贴近角色语气需求，但需要实际机器评测算力、延迟与并发。没有在本轮安装模型或宣称已测试音质。
- [Web Speech 本地音色标记](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesisVoice/localService)：本地/远程服务区别。本实现不使用默认远程回退。

免费权重不等于免费公网算力。后续可以在用户明确选择并提供的本地设备上测试 Kokoro 或 Qwen；本机服务不会自动成为所有 Vercel 访客可访问的稳定后端。未确认运行环境前不安装大模型、不开放本机公网端口、不承诺永久免费托管。

## 资料分离

userProfile 是用户直接编辑的真人资料，playerPersona 是世界探索用的虚构角色，memories 保留原有可确认的聊天记忆字符串。旧存档无 userProfile 时为空，不从角色信息自动填充。手动云快照包含新增字段，个人助手使用当前资料优先提示；创作不自动获得新资料。

尚未实现：每条记忆的完整来源/时间/纠错历史、自动跨设备同步、神经 TTS 情绪表演、全站连续配音。
