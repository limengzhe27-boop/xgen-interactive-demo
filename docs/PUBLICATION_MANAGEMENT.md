# 作品管理验收 · 2026-09-07

## 本轮实现

- 我的世界顶部：本机草稿与云端公开版本分开；原有探索和聊天记录保留。
- 登录作者查询自己的已发布／已下架作品；不能通过传 owner 参数查看他人未发布作品。
- 下架及重新发布已有版本；下架不删除已有图片和别人已保存的副本。
- 修改状态使用 owner + id + updated_at 条件，旧页面冲突返回409；发布暂停时仍允许下架。
- 新发布保存 sourceId 关联原稿，公开列表剔除此内部关联标识。编辑原稿后再次发布沿用同一作品ID。旧发布没有来源时不按标题猜测关联。
- 公共列表读取上限与当前站点200个作品上限一致，不再只取最近20个。

## 验证与边界

- 137项测试通过；新增内存存储替身的作者A发布、B读取、B越权失败、A下架、旧版本冲突、重新发布和更新不重复流程。
- 私人字段标记没有进入发布文档；图片仍沿用显式同意和归属检查，不调用生图。
- Tabbit独立合成账号页面，390×700与1440×900检查；手机无横向溢出，确认下架只发送一次请求。账号和作品响应为替身，未修改真实存档或公开记录。
- 本轮没有真实A/B登录账号的数据库发布验收，不宣称公开发布全面开放；WORLD_PUBLICATION_ENABLED保持现状关闭。
- 尚缺跨设备缺失原稿时从公开版本恢复完整编辑、早期发布来源迁移，以及实际生产账号的完整发布/进入/角色聊天验收。更新内容仍使用原发布RPC，尚未加入全文更新的乐观版本冲突保护（状态变更已有）。

下一步先完成真实账号A/B链路与内容更新冲突保护，再开启发布开关。语音任务暂停，新网关仍未接入。
