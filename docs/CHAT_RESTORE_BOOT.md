# 刷新恢复不经过首页

2026-09-10

- 根因：账号pending阶段仍挂载默认home工作区；账号确认后的新工作区又在本地存档恢复前先渲染home。恢复effect随后切到chat，造成闪屏及无用首页工作。
- 修复：pending阶段不挂载工作区；本账号storageReady前不挂载任何业务页面，只显示恢复状态。账号复核/切换隔离保留，不以缓存账号绕过验证。
- 隔离浏览器通过MutationObserver观察刷新整个恢复阶段，没有出现gallery-discover节点；原聊天、招呼、未发送草稿仍恢复，明确返回后刷新停在首页。桌面和两种手机尺寸无输入溢出。测试回复使用模拟API，无外发私人会话。
- 减少重复挂载与首页图片加载，不代表降低外部模型回复延迟；网络账号验证与首次JS加载仍需要时间。
