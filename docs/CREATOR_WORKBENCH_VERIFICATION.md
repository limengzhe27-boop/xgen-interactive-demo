# 创作工作台验收 · 2026-09-06

## 本轮范围

- 四个创作步骤共用一个 Agent 讨论栏，传递当前章节、最近编辑字段、当前角色和世界框架。手机提供编辑／讨论切换。
- 角色可手动填写独立目标；任务支持主线／支线、角色归属、困难、完成条件及前置任务。删除角色时重排旧索引 ID，并删除该角色独占的任务、清理失效前置。
- 手动世界建立角色级目标和结局，只要求该角色可完成的主线；支线不强制决定结局。保留旧格式（未设置归属表示所有角色）。
- AI 提案按名称、背景、角色与任务、核心目标、成功／失败条件、复杂度、意外、世界困难和预设事件分组采纳。角色与关联任务暂时作为一组，不是每个字段的独立补丁。
- 分组比较前后值，采纳与撤销都检查是否有后续手改；不同分组互不覆盖。保留最近 12 次采纳记录，刷新或切换草稿后撤销记录清空。
- 修改目标／关系不失效角色图片；修改外观等视觉输入才失效对应图片，不自动调用生图。

## 已验证

- 74 项自动测试通过；包括旧存档、角色选择、图片缓存／配额、账号隔离、任务图、分组采纳与冲突撤销。
- TypeScript 与正式构建通过；本轮新增组件和逻辑定向 lint 通过。主页面既有 Hook 依赖及状态标签 lint 问题仍存在，不宣称全仓 lint 零问题。
- Tabbit 独立合成账号、本地 1440×1000：填写两人不同目标和专属任务 → 手动生成 → 保存试玩 → 选顾言舟；显示顾言舟目标和任务，不显示苏晚任务。
- 浏览器合成模型响应：Enter 只发送一次；名称建议单独采纳并撤销；等待响应期间手动改名后，旧建议被拒绝覆盖。
- 390×844：编辑／讨论切换、第三步 Agent 请求携带意外规则章节，只有一个输入框，页面无水平溢出；查看了桌面与手机截图。
- 测试不读取真实存档，不发送用户资料，不调用图片生成；合成数据清理仅针对独立测试账号。

## 未纳入本轮／下一阶段

- 角色与任务的更细粒度独立建议补丁、复杂结局条件的完整可视化编辑，仍需后续深化。
- 账号绑定的虚构身份、世界能力限制、私人内容云同步与迁移、公开发布／撤回的完整验收未完成。公开发布仍保持关闭，不宣称已可公开。
- 本轮不新增付费图库、不修改免费存储方案。
