# 瑜伽序章重拍：先让观众看懂关系

## 已确认方向

用户要求非露骨但明显的婚外越界、清楚的私教课场景、连续动作与首屏观看。不是增加暴露程度或把不相干的画面串起来。序章是固定过去；停在当前消息未回复处，玩家仍可从任何角色开始。

## 付费前分镜

1. 第一段10秒：瑜伽垫、镜墙和训练动作建立私教场景；教练扶肩背/腰侧指导，女主主动转身搂肩，双方短暂亲吻并相拥。两名成年人，全程着装。以现有原创林栀、陆晨肖像做参考，不使用真人照片。
2. 先实看第一段。合格才以其末帧续拍第二段10秒：手机亮起，女主由沉迷转慌张，收起手机、推开私教，取开衫走入更衣隔间，关门、看手机但没有回复。必要时根据实际成片调整续拍起点，最多两次提交；不循环重试、不一次盲投所有镜头。
3. 字幕明确“结婚九年／对方是私教，不是丈夫”。消息由网页叠加，避免模型生成不可读手机文字。丈夫只催接孩子，尚不知道越界；未来账单、骗局与离婚不提前展示。

## 连贯性与验收标准

- 同一对角色、服装、瑜伽馆空间；第二段接首段末帧，不重新随机选演员。
- 观众能指出谁是妻子、谁是私教，看到超出训练的双方亲密动作，而不是只凭一张温水照片猜测。
- 消息打断亲密关系，走进隔间后的未回复状态衔接现有17:40开局；不替玩家作出“撒谎／让丈夫接孩子”等后续决定。
- 没有裸露、性行为、儿童出现在亲密场景；片段不是真实人物事件记录。
- 只有下载并实看的成片才切换线上链接；记录实际请求数、尺寸和文件大小，不声称绝对同脸或精确扣费金额。
