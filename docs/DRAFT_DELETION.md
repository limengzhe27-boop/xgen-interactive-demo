# 本机草稿删除

2026-09-08：我的世界 → 本机草稿，每项“继续编辑”旁提供“删除草稿”。确认弹窗展示标题与删除范围，取消不变更数据。

删除的是本机创作记录及其创作讨论。删除当前编辑的草稿时清空创作编辑器，不保存旧草稿；待执行的自动保存通过删除 ID 防护避免重新插入。创作请求进行中不允许删除。公开版本、独立角色会话、体验存档、个人资料与云端图片不删除；旧手动云存档也不自动改写，恢复旧云存档可能带回草稿。不提供撤销，确认前明确提示。

验证：类型检查、164 项回归通过；Tabbit 独立 3105 测试页创建临时草稿，验证取消保留、确认移除、刷新不复活。只删除测试草稿，未操作真实用户数据，未调用付费模型。
