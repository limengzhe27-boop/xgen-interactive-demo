# 三分支提前编排

2026-09-11。VideoExplorer 在用户开启视频探索后执行。

- 第一次进入先准备当前三个选项；未就绪的选项不可提交。用户自定义文字仍按需编排。
- 当前行动已裁定并保存为 pending 后，在本段视频生成/播放期间，并行编排下一轮三个候选行动。仅调用现有文字 Agent，不提交三段 FAL 视频。
- 每个候选保存裁定响应与完整视频提示词。点击就绪选项直接提交所选提示词及实际末帧，不再调用文字模型。
- 推演的世界状态只供候选编排，不修改真实存档；新视频开始播放时才提交该回合事实。未来候选不提前展示。
- 缓存随账号隔离的标签页存档保存，键包含请求中的世界、角色、状态、叙事、选项与参考帧模式。实际末帧在提交时读取，不以封面替代。
- 部分失败保留成功分支；手动重试只补缺失项。默认选项未就绪时不倒计时，不自动重试文字失败，不提前购买视频。
- 原 turnKey、提交前持久化、恢复原任务与原生音轨要求保持不变。

边界：这是以额外文字模型用量换取等待重叠，不是视频渲染加速。首次准备、文字服务异常、自定义行动及 FAL 排队依然需要等待。没有执行真实模型或付费视频验收。
