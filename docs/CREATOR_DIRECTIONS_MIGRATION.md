# 创作走向字段迁移（2026-09-21）

- CreatorBrief 的 successCondition / failureCondition 改为 preferredDirection / alternativeDirection。
- UI 保持“预期走向 / 其他走向”；二者可留空，不要求一好一坏，不代表已发生事实。
- 草稿加载、历史版本恢复、待采纳建议、局部变更与整包撤销、旧客户端 API 输入及模型旧格式输出均兼容旧名。显式新字段（包括空串）优先；缺省不覆盖。
- 任务自己的 successCondition 不改：它是具体任务完成依据，不是整个故事的胜败。
- 生成世界指令取消强制 failure 结局。已有世界 endingConditions 的历史标签不批量重写，运行时继续按事实条件检查。
- 六横六纵增加适时补缺规则：先完成本轮请求，再针对开场、后续、目标或“下一步”检查一个体验缺口；局部改字不追加问卷，开放故事不强造任务或结局。

## 验证边界

- 126 项创作、迁移、手动建世界与结局测试通过；生产构建通过。
- 扩展界面套件 26 通过、2 失败：旧首页文案断言和旧 setCreatorMessage(seed) 源码断言。本轮未改这两个功能来迁就测试。
- 新指令的真实模型多轮表现尚未验收；静态规则检查不代表引导质量已验证。
- 手动建世界仍将走向作为待事实成立的收束候选，不代表拥有独立的可视化收束条件编辑器。后续需单独设计“发展意向”和“精确收束条件”的完整区分。
