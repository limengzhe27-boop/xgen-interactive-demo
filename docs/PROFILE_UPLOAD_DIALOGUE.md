# 上传形象、记忆记录与多角色对白

- 虚拟形象支持 JPG/PNG/WebP 本机导入，原文件最多8MB；重新编码为最长768px的JPEG，去除文件元数据，结果最长240000字符。只保存图片数据，不保留文件名；不发送给模型、不自动公开。保存身份后按账号留在本机，私人云备份仍需用户主动执行；有2MB快照上限。
- 上传图片不因手动改外观或采用AI文字草案而清空。已有会话使用进入时快照，不随身份更新。
- 聊天记忆新确认项记录“Agent提议、用户确认”与确认时间；手动修改最多保留5次旧值。旧记忆不补造时间或来源。历史仅供显示，模型仍读取当前记忆字符串；删除本机记忆同步删除本机历史，不删除旧聊天或云快照。
- 修复世界对白取首位说话者并拼接所有台词的错误。新回合按角色ID和可见范围保留发言顺序、独立头像与名字，存档保留数组，下一轮上下文包含每句的姓名。旧存档中多行拼接对白明确标记归属缺失，不猜测分配。
- 未执行数据库迁移、真实双账号公开发布或网关视频任务；语音仍暂停。新剧本多轮真实模型质量评估仍待做，不把结构测试等同叙事质量保证。
