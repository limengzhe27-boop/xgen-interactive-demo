# 事件追加执行（2026-09-16）

本批是创作执行保护，不是完整事件参与数据模型重构。

- 明确追加节点指令走执行规则；疑问、讨论、否定不自动执行。
- 对已有图，只允许增加节点与指向新节点的连线，保留原节点文字、原连线、共同起点、所有首次入场与认知。不自动纠正旧草稿的入口。
- 显式节点 ID 必须成为新增节点的连接父节点。画布提供携带标题和 ID 的 Agent 构思入口，点击先填入消息，由作者发送。
- 无未采纳建议时，校验通过的追加写入私人草稿并保留撤销；不发布、不生成媒体。
- 有未采纳建议时继续展示建议，避免顺带采纳其他设定。
- 生成期间草稿有修改则不自动写入。缺失、重复同名、空场景、断连、循环不报告完成。
- 模型声称完成不能替代数据。追加结果回复由程序依据新节点生成。

旧作品有画布且没有待确认续写提案时，明确追加节点也走同一共创路径；成功后退出旧续写状态，继续编辑同一私人草稿，避免旧 base 覆盖新画布。已有完整续写提案仍保留原确认流程。完整续写允许仅新增事件或角色，不再强制新增任务。

非入口节点不再默认突出“从此处入场”；入口调整折叠展示并说明清空认知的影响。

节点新增可选 trigger 与 possibilities（actor/action/consequence，最多6项）。画布折叠呈现，不要求填写；保存、发布白名单和恢复保留这些字段。actor是人物称呼描述，不是稳定角色ID，不自动跟随角色改名；首次入场与角色知识仍独立。共创指导允许Agent随讨论补充，体验提示词只把它们作为可能性，不作为历史或强制玩家行动。这不是确定性条件执行引擎。

待完成：所有旧作品续写讨论路径统一；角色参与的稳定身份绑定与运行时条件裁决；更广泛意图识别；浏览器真实多轮、手改与撤销体验。本批离线覆盖与构建不等于模型每次都能创作成功。
