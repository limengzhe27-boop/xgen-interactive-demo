# fal 视频探索试用（2026-09-09）

## 范围与实际结果

- 新增独立 `/video-explore/[worldId]` 试用页，入口在序章对比页。固定第一人称跳过选角；多角色先选择角色，再出现三个行动和自由输入。
- 主动开启后，前台等待15秒默认选第一项；输入、失焦、暂停、错误和生成中不倒计时。每次最多两段，沿用服务端每天单身份2段/全局6段的额度保护。
- 2026-09-09真实提交一次5秒请求，fal返回403：`User is locked. Reason: Exhausted balance.` 没有任务编号和成片；不自动重试。实际动作、原生对白与延迟尚未验收，不能把模拟测试称为模型跑通。
- 用户明确授权将本地 FAL_KEY 配置到现有 Vercel 生产项目，已保存为 Secret，仅服务端使用。配置成功不代表余额充足。

## 接线与声音边界

采用官方 [MiniMax H3 Max image-to-video API](https://fal.ai/models/minimax/h3-max/image-to-video/api)，每次5秒/768P。多角色第一段以对应角色位置重建第一人称，之后使用真实解码末帧续演；不把第三人称封面当作第一人称末帧。

世界 Agent 先生成可见后果与三项选择，视频提示只提取可见叙述、对白、外观，不附整个世界秘密档案。要求原生中文对白、动作声和环境声，不调用后配TTS。下载后检查真实MP4音轨，无音轨拒绝交付；存在音轨不证明对白准确、可懂或原生能力已实证。

任务先原子占位再提交；重复回合复用记录，不因超时重买。生成结果存私人媒体空间，轮次状态在新视频开始播放后才提交。失败保留旧世界状态。试用使用独立会话，不覆盖原图文存档；离开后不会后台无限生成。

## 三个修仙对比版本

- 20秒原版：无声，仍是正式世界原前情。
- 10秒第二版：历史后配音检查片，未完成正式验收。
- 15秒第三版：Seedance原始原生音轨样片，有视角漂移，未替换正式世界。

三版均在 `/prologue-comparison` 明确标注，不把后配音称为原生，不把新样片情节偷偷写进旧世界。
