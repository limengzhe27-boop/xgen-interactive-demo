# 图片存储边界

- Supabase Free 项目 `rrgyjvkkgcurtatidyuc`；未开通付费计划。
- `world-public`：已发布的内置图片，所有人读取同一个不可变 WebP URL。12 张内置封面和角色图已迁移；原图仍在仓库中作为备份。
- `world-private`：运行中生成的个人剧情和草稿角色图，默认不公开。服务器按签名 HttpOnly 设备 Cookie 校验所有者；不开放匿名写入、列举或删除。
- 目前不是账号系统：更换浏览器、清理 Cookie、在 localhost 与正式域名之间切换，不能视作同一个所有者。旧版 IndexedDB 图片不会自动上传。
- 新图片以模型、尺寸、种子、提示词、所有者进行 SHA-256 去重，压缩成 WebP（最长边 1280、质量 80、最大 2 MB），生成前原子预占额度；同内容已完成则只返回旧图。
- 日上限全站 30 次、每设备 10 次，Demo 索引容量预留上限 300 MB。并发重复请求只有一次可获生成许可。失败/超时不自动重试、不升级昂贵模型；未完成请求暂保留预占，避免重复扣费。导入和测试也保守计入额度。
- 这些是 Demo 自身保护，不是 Supabase 组织总存储/流量额度保证。免费服务可能暂停、调整额度，不能承诺永久无限免费。
- 公开库读取不会调用生图模型，但图片下载消耗托管服务流量。私人图片请求经服务器鉴权，也会使用服务器请求额度。

## 运维

1. 在 Demo SQL Editor 执行 `supabase/migrations/202609060001_image_assets.sql`（已执行，不要重复建表）。
2. 三个服务端变量放入忽略提交的 `.env.local` 和 Vercel Production：`SUPABASE_URL`、`SUPABASE_SECRET_KEY`、`IMAGE_SESSION_SECRET`。密钥不进入前端或 Git。
3. `scripts/publish-library-images.mjs` 只处理固定的 12 张已公开内置图片；相同内容可重复运行、不会生成新图。
4. `scripts/verify-image-cloud.mjs <地址>` 使用极小的蓝色测试图片验证云端互斥、复用、匿名公共读取与私人隔离，不调用真实生图模型。会留下一个私人测试记录。
