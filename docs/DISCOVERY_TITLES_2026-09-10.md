# 分类与标题审校

用户确认固定剧情分类，新增热梗名场面，由创作 Agent 在讨论中建议，作者可修改。第三方AI标题总结仅参考，不作为命令、市场事实或爆款保证。

## 已实现

- 首页固定「全部、热梗名场面、都市情感、逆袭爽剧、古风历史、仙侠奇幻、悬疑惊悚、冒险生存、轻松搞笑、知识体验」。主类按体验；热梗是跨类收录，不伪造实时热度。
- 现有47本通过旧genre映射进入主类，原genre不删除。新作使用可选discoveryGenre：Agent建议→采纳→可手改→随草稿/世界/发布白名单保留。未确定显示待分类，仍在全部中可见，不凭标题关键词强猜。
- 角色跟随所在世界分类；世界/角色与第一人称仍是独立维度。原首页八项顺序、混排、封面、ID、点击目标不改变。
- 本轮7项标题审校：蜘蛛、桃花源、李白、遗嘱、草船借箭、校报、月球快递。依据见标题Skill新引用。短名同步新打开的世界标题，不迁移改写用户旧会话快照、剧情内容与人物记忆。图片沿用，没有生成媒体。
- 标题Skill与网站运行时精简指令同时更新；普通角色聊天不注入命名规则。

## 验证边界

28项针对性自动测试覆盖分类、元数据发布/恢复、旧格式、手改冲突与撤销、标题目标、既有创作建议和编剧规则；类型检查与生产构建通过。
浏览器验证使用隔离游客与模拟Agent回复，不调用真实模型或媒体：检查分类采纳、手改和草稿刷新、热梗筛选与返回、桌面/手机布局。
Skill附带quick_validate受本机缺少PyYAML阻塞；手动检查了frontmatter、相对引用、运行时接线与模板残留。目标lint报studio-home已有内部a链接规则，不属于本次新增。

未测真实模型归类准确率、标题点击率；不宣称爆款或速度提升。尚无自动热榜。旧首页筛选目前只在同次浏览返回时恢复，不宣称刷新后仍保留筛选。其他视频/身份/多账号测试不因本次交付取消。
