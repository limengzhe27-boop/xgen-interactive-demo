# 世界 Agent 入场建议｜2026-09-06

## 已实现范围

- 玩家先选创作者开放的剧情位置，再主动请求 DeepSeek 提供代入建议；不自动推进、不生图。
- 三种能力政策：仅原角色能力、固定授予、Agent 从创作者清单中挑选至多三项。第三种政策没有清单时关闭自带身份入场。
- 模型只返回所选角色 ID、代入建议、能力子集和愿望限制；角色 ID 不允许更换，能力必须逐字匹配清单（包括限制），不能重复或超过三项。语义建议不写入世界规则，只有能力子集在确认后生效。
- 前后端均采用输入白名单，仅发送虚构姓名、背景、性格、外观、愿望能力、本轮偏好、世界标题／时间、所选角色公开身份／目标及政策。不发送账号、头像地址、个人记忆、私人对话、角色秘密和其他世界字段。
- 确认后只生成已有世界的独立会话快照。目标、任务 ID、前置、关系与知识继续沿用；探索和角色会面均支持保存恢复。
- 30 秒客户端等待上限、25 秒服务端模型上限；没有自动重试和 mock 成功。取消等待不保证外部请求停止计费。切换世界、角色、档案或账号即销毁本轮建议，迟到结果不写回。

## 验证

- 94 项自动测试通过（新增 6 项），类型检查与改动文件 lint 通过，正式构建通过。
- Tabbit 独立测试账号和虚构世界：1440×1000 桌面、390×844 手机无水平溢出；Enter 发送、Shift+Enter 换行；建议不自动确认；改偏好后失效；清单外“读心”拦截；502 保留偏好；取消与角色切换后丢弃迟到结果。
- 探索和角色对话两入口均带入“林星”及选中的谈判能力；角色会话刷新后可从“继续”恢复，能力仍保留；重新选角返回原世界，必须重新取得建议。
- 本地正式构建真实 DeepSeek 请求返回 HTTP 200，准确选出“善于谈判，但不能替他人同意”，未授予读心。只发送本轮原创虚构测试材料。
- 上述浏览器验收图片 POST 次数为 0。仅清理虚构测试账号的本机键，不删除真实存档。

## 尚未实现／不能推出

- 仍代入已有剧情角色，不是创造一个与原班角色并存的新参与者。原背景是参考，不直接改写世界身份。
- 清单校验是精确结构校验，不是完整语义安全或反作弊系统；世界定义目前来自客户端快照。创作者政策的服务器权威版本、签名入场凭据属于后续公开世界基础设施。
- 个人虚构身份仍按账号保存本机，尚无云同步；公开发布仍由既有开关关闭。本次不改账号、云数据库或发布开关。
- 模型代入建议的文学质量不由单个测试保证；现有故事推进规则继续承担任务、物理和知识约束。
