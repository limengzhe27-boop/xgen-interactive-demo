# 开放走向与作者关键事件

多个事件或行动不是必选其一的封闭答案库：条件不成立时可以都不发生，玩家也可以引出符合世界的新方向。单一后续也不表示必然。互斥走向不能合并成已发生历史，非互斥事件可先后发生。

创作时围绕关键局面优先给2～3个有差异的可能方向，不要求每个小动作都分叉。不同事件放在后续节点；同一局面的应对放在possibilities，新增可选condition说明适用条件。trigger仍描述节点条件。

eventIntent缺省/possible：可能发生。key_event：作者明确指定希望最终发生的关键事件。画布提供显式选择；共创响应处理保留作者既有标记，不接受模型自行升级或取消。关键事件仍不是历史事实，不授权代替玩家行动；时机、方式、知情者及后果保持开放，不能突破世界规则。

条件和性质随发布、恢复保留，旧草稿无须补字段。创作、世界生成及体验提示同步使用同一规则。运行时目前依靠模型判断文字条件，尚无确定性的条件执行器，不能保证关键事件必达或每次因果推演正确。首次入场与当前存档事实不改动；不批量重写已有故事，不生成媒体。
