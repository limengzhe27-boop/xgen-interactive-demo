# 视频耗时记录

入口：视频探索右上角剧情记录 → 耗时记录。最近300项按当前账号保存在本浏览器，导出JSON便于多样本比较。不上传浏览器诊断，不记录提示词、行动正文、图片、对话或令牌。

- 脚本编排：浏览器文字请求开始到有效响应返回，含网络和服务端校验；不是纯模型推理。
- 末帧读取：独立解码器启动到读出末帧。
- 视频提交至可用：本页提交开始到收到可用结果；停止观察不代表模型停止。
- 排队＋生成：服务端提交前到首次查询得知COMPLETED，含提交网络、排队、生成与轮询延迟。没有供应商精确时间时不伪造纯推理时间。
- 服务端取回成片：结果URL返回后下载并读取成片的时间。
- 服务端保存成片：私有对象存储上传完成的时间，不含最后一次状态数据库写入。
- 缓存下载：浏览器后台缓存开始到完整Blob就绪；中止、失败独立标注。
- 加载至首帧：播放器换源到loadeddata/可解码首帧。缓存命中另记，命中不意味着解码零耗时。
- 播放中缓冲：waiting到下一次playing；切换/离开是中断，不计为完成。
- 选择至播放：用户选中到playing，包含尚未完成的相关阶段。

阶段互相重叠，不可求和充当总时长。均值只统计完成样本。刷新中的未完成记录标为中断，不将离线时间计为成功样本。服务端时间跟随现有私有媒体任务保存，旧任务没有的字段保持未知。

并行保存：服务端完成格式/音轨检查后开放同源鉴权播放，私有存储上传在响应后执行。数据库仍为queued，接口以persisting=true表示可播放但未持久保存；存储完成后同一地址读取私有文件。浏览器另行有界查询保存耗时，不阻塞播放。未声称模型完成后立即零等待：首次服务端下载与检查仍存在。
# 测试批次

脚本请求去重：仅当前页面、同账号同存档且完整请求一致时共享进行中或60秒内结果，最多6项；角色/状态/行动/有无参考帧不同不复用，失败移除，离开或账号切换取消并清空。不删提示词或请求字段，不改变模型输出要求。效果订阅结束可不再应用结果，但原有文字请求允许短暂完成供重入复用；不触发新视频生成。脚本计时只记录真实请求，复用不重复计算样本。

首帧预准备：仅一个已下载候选使用备用video元素预加载，不调用play、不出声；选中相同资源直接提升该元素，其他选择正常加载。准备失败不会触发重新生成。切换后台时撤下候选。前台等待显示从本次点击/恢复查询开始，后台任务submittedAt不变。

播放快路径：对支持 Range 且前256KiB包含完整音轨结构的MP4，先通过结构检查开放私有播放，完整取回/保存后台继续；其他布局保留全文件检查。音轨存在不等于对白质量验收。模型、分辨率、时长、提示词均未改变。切换视频首帧未就绪时暂停其他未完成预下载，已缓存成片保留，首帧就绪再继续预下载。新的快路径下“服务端取回成片”可以发生在播放之后，不可串行累加。

耗时记录中的“开始新一轮测试”只切换后续新分支的统计归属，不发起生成、不清空历史。已有分支的迟到结果仍归原批次；选择历史批次只影响查看，不改变正在记录的批次。原有未分批记录归“历史记录”。全部批次合计仍保留最近300项，导出包含所有保留记录及批次字段；长期比较请先导出。数据仅保存在当前浏览器账号范围内。
