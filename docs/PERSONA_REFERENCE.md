# 虚拟身份的原作参考

## 使用

“我的 → 虚拟形象 → 我的形象 / 编辑虚拟角色”中的“补全原作设定”是可选工具。输入公开角色名、确认条目与作品，再整理资料；默认避开后期剧情。结果可直接修改，默认只补空字段，勾选后可替换已有文字，始终保留图片。采用不是保存；仍需点击原有“保存身份”。

原作参考、用户自定义版本、入场授权互相独立。补全不能改变世界规则、原角色、关系或现有探索；能力仍需要世界适配。参考不是完整知识库，也不是事实正确性保证。

## 来源与隐私

- 海贼女帝使用 ONE PIECE 官方2020人物专题，明确非最新全集；其他角色通过中文维基百科查找并选择条目，社区资料不称为官方。尚不是通用搜索引擎，多译名/冷门角色可能查不到。
- 只把查询框里的公开名称发给百科；整理只向现有公司文字网关发送选中网页正文、标题和避剧透选项。不附带用户草案、聊天、记忆、图片、所有者或世界秘密。来源引用不会额外传入入场与身份设计模型。
- 服务端固定公开站点、禁止重定向、不接受任意URL，限时/限响应大小；正文剥离HTML/脚本，提示中将网页视为不可信数据。每个字段要求原文证据，引用不存在的字段被清空；证据匹配不等于语义百分百准确，用户仍需审阅。
- 仅登录用户、同源请求、校验账号范围。每实例每账号每分钟最多6次、一个并行请求；这是进程级防重复，不是全局计费限额。公开正文短期缓存最多40条，5分钟；用户草案不进入共享缓存。
- 原作来源标题/地址/时间与被采用字段随原账号身份本机保存，可手动云备份。保留出处不代表后续手改还是原作，可单独移除标记。旧存档兼容；不自动联网刷新，不自动生图或视频。

## 本轮检查

- 公开女帝官网/专题及孙悟空百科查询实际读取成功；女帝专题经公司文字模型返回石化、三种霸气、性格与外貌。基础页信息不足已弃作优先来源；专题曾读取超时一次，修订读取上限后成功，失败不改身份、不自动重试。
- 模型输出可能出现中文译名差异，来源也可能不够详细；默认避剧透是整理约束，不保证完全无剧透，原网页仍可能含后期内容。
- 自动回归263项、类型检查通过；包含缺失证据、未知链接、用户优先、账号隔离、取消接线、来源恢复、纯服务端渲染与接口游客/跨站拒绝。真实来源与模型验证使用公开角色，不改真实用户存档。
- 不把服务端渲染/函数测试称为真实登录浏览器交互或跨设备验收。视频测试按用户指令暂停，本轮无视频/图片/TTS生成，无fal接入。
