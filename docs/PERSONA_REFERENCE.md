# 虚拟身份的原作参考

## 使用

“我的 → 虚拟形象 → 我的形象 / 编辑虚拟角色”中的“查漏原作设定”是可选工具。输入公开角色名、确认条目与作品，再点击“对照我的设定”。只保留一套主身份表单；结果为最多六条具体增补/差异，支持展开调整单条补充。默认避开后期剧情。

增补只追加到已有文字，永不整段覆盖；差异只提醒，尊重自定义版本，不自动采纳。没有增量时直接说明“本次来源未发现可补充项”，不承诺档案已完整。超过字段上限则整批不写入，不截断原文。对照等待期间修改主表单会让旧建议失效，需再次主动对照。采用不是保存，仍需点击原有“保存身份”；图片不变。

原作参考、用户自定义版本、入场授权互相独立。补全不能改变世界规则、原角色、关系或现有探索；能力仍需要世界适配。参考不是完整知识库，也不是事实正确性保证。

## 来源与隐私

- 海贼女帝使用 ONE PIECE 官方2020人物专题，明确非最新全集；其他角色通过中文维基百科查找并选择条目，社区资料不称为官方。尚不是通用搜索引擎，多译名/冷门角色可能查不到。
- 只把查询框里的公开名称发给百科。点击对照前显示发送说明：所选网页与当前五个虚构文字字段（名称、背景、性格、外貌、能力）发给现有公司文字网关，用于查漏。服务端再次白名单提取字段，不附带真实资料、聊天、记忆、图片、所有者或世界秘密。来源引用不会额外传入入场与身份设计模型。
- 服务端固定公开站点、禁止重定向、不接受任意URL，限时/限响应大小；正文剥离HTML/脚本，提示中将网页和草稿视为不可信数据。每条建议要求原文证据，引用不存在则过滤并显示数量；过滤全部不冒充“资料已完善”。同义重复与语义冲突主要由模型判断，不能保证每次完全准确。原作查漏不混入模型凭空创作，创意设计仍在独立的“让 Agent 帮我设计角色”入口。
- 仅登录用户、同源请求、校验账号范围。每实例每账号每分钟最多6次、一个并行请求；这是进程级防重复，不是全局计费限额。公开正文短期缓存最多40条，5分钟；用户草案不进入共享缓存。
- 原作来源标题/地址/时间与被采用字段随原账号身份本机保存，可手动云备份。保留出处不代表后续手改还是原作，可单独移除标记。旧存档兼容；不自动联网刷新，不自动生图或视频。
