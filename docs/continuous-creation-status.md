# 持续创作：第一批实现范围

## 第三批：同存档切换（2026-09-10）

图文和视频探索增加切换角色入口；保留存档 ID、时刻、任务、世界事实和已有视频。分别保存各角色实际体验到的物品、线索、记忆、关系和经历，切回时恢复；使用当前角色位置，不应用新开局 entry。切换不调用生成服务、不推进回合。视频生成/播放期间禁止切换，切换后暂停自动选择并清除旧视角末帧；空视频状态亦可刷新恢复。其他角色的缓存不发送到当前角色的模型提示中。

限制：固定单角色、自带身份适配存档暂不开放切换；离开视角后各角色的新见闻、物品流转尚无完整独立模拟，中后段角色的初始私密资料保守不授予。共享世界事实仍交给世界 Agent 裁决，不能声称模型绝不会泄露秘密。尚待完成旧存档升级、不可变版本历史、剧情边界和催更统一处理。

作者打开已有创作，点击“继续写后续”，在原聊天中说明追加内容。使用真实 generate-world 请求，服务端共享 CONTINUATION_GUIDANCE，前后端均使用 appendStory 合并和校验。未确认提案可继续讨论、退出或刷新恢复；确认后加入草稿，再保存试玩或进入现有公开发布流程。

原人物、开场、已有任务保留；新增任务、人物、地点、规则可追加。简化编辑器未改动时直接保留完整世界，避免丢失 Agent 生成的结构。已保存的作品快照与编辑草稿分离。首页人数为确定性演示数字，明确标注“演示”，不作为真实业务数据。

## 本批不宣称完成

- 正式站 WORLD_PUBLICATION_ENABLED 当前为 false：公开发布仍受原开关和账号授权控制。
- 不可变发布版本历史、跨设备版本冲突与回滚尚未实现。
- 老存档接入新增剧情、世界时间不变的角色切换、角色登场节点和认知隔离前情属于下一批。
- 单主角跳过选择、剧情边界文案和催更入口尚待统一调整。
- 当前仍遵循现有世界大小限制；不是无限续写。
- 本批未调用付费模型作线上生成验收，不声称真实生成与公开发布已经端到端验证。

## 第二批：角色入口（2026-09-10）

- 增加 Character.playable/isDefault 和可选 entry；旧角色默认可体验，旧 fixedRoleId 限制保留。
- entry 使用剧情节点标识、此前完成任务、世界事实、角色已知事实和眼前场景；发布时验证任务及其前置引用。不强制创作者填写这些字段，由 generate-world 的共享规则根据明确设定生成。
- 公开 Hook 与角色前情分开；选角前不展开人物秘密。中段角色选定后可阅读 knownFacts，开始角色按原流程直接进入；单可体验角色省略选择。
- 图文及视频初始状态共用角色入口应用函数；不把 worldFacts 当成可见前情，不读取其他角色秘密来生成前情。当前前情是作者/创作 Agent 保存的已知事实，不额外调用模型改写。
- 多角色视频先选人；瑜伽馆旧片仅用于林栀。其他角色使用自己的开场和行动，未伪造其他角色的前情视频。既有生成片段不删除、不重新购买。
- 尚未实现同存档角色切换、完整剧情节点世界快照（各 NPC 在不同节点的位置等）、旧存档升级及发布版本历史。不能将入口已知事实过滤称为完整的运行时认知隔离。
- 不修改内置故事后续内容，不生成媒体；未做真实付费模型验收。
