# 六横六纵运行时接线第一批

版本：six-by-six-2026-09-20。

## 本批范围
- lib/creator-skill-routing.ts 提供六横、六纵的精简运行指令。
- 创作接口实际调用 creatorSkillGuidance，与现有响应契约、画布校验及可选 TypeSafe 焦点建议共同使用，不新增外部请求。
- 当前请求的显式主题优先，已有辅助焦点其次，无法判断时使用方向讨论兜底。路由仅为建议，不授权变更、不代替作者最新意图。
- 普通改名等局部编辑不加载纵向方法；每轮最多选择两个当前适用方法。题材本身不触发秘密、阴谋或全员生成。
- 状态接口暴露版本号，用于核对部署，不暴露作者内容。

## 准确边界
这不是完整加载外部 research Markdown，也不是十二个独立 Agent。运行时为首批精简摘录；研究规格修订需人工同步运行指令并复核。
初版选择是有限词汇规则加已有可选焦点判断，不是经过多轮验证的完整语义调度；否定语句、多主题及简短承接可能需要模型依据原话调整，后续应补显式会话阶段与所选对象。
保持现有人物全名单提案和按位置角色引用；稳定 ID 的全链路迁移、字段级冲突保护与所有成果透传仍待后续，不在本批完成声明中。
没有改动工作区布局、运行时故事引擎、账号、视频制作或付费策略。

## 检查
新增路由测试覆盖六横六纵、当前主题优先、局部编辑及不全量加载。与响应/追加测试一起运行；生产构建及正式接口复核另行记录。本地断言不等于真实模型质量或浏览器端到端验收。
