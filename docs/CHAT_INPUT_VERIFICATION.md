# 2026-09-06 聊天可用性修复

## 修改范围

- 个人 Agent、创作 Agent、角色聊天、探索行动统一 Enter 发送，Shift+Enter 换行。中文输入法组合输入及 keyCode 229 不发送，空白、禁用与长按重复 Enter 不发送。
- 普通剧情、角色资料、目标和任务编辑字段维持原有换行，不自动提交。
- 角色聊天显式使用当前账号创建文字客户端，生图请求与图片缓存的恢复、读取、写入也使用同一账号。账号变化由现有 AccountBoundary 重建工作区并中止旧会话请求。
- 角色聊天增加同步请求锁，避免同一轮重复提交；普通对话继续复用图片。

## 本地验证

- 65 项自动测试通过；生产构建通过。
- 本次新增组件、工具及测试定向 lint 通过；app/page.tsx 仍有原有 Hook 依赖与语义标签告警，本轮不处理无关重构。
- Tabbit 独立 3102 测试页：登录身份 A 连续两轮聊天；身份 B 不加载 A 会话；游客聊天；四类消息框 Enter 发送；Shift+Enter 换行；组合输入不发送；创作失败保留输入。
- 生图请求携带账号 B；返回合成测试图片后写入 B 专属 IndexedDB，再次请求相同场景命中缓存，无第二次生成请求。
- 390px 手机角色聊天无横向溢出。
- 浏览器使用拦截的合成账号、回复与测试图片，未上传真实存档、个人对话，也未调用付费模型。该验收证明交互与请求链路，不代表真实模型质量验收。
