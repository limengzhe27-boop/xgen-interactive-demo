# 世界入口顺序 · 2026-09-11

## 新建体验

1. 点击首页世界卡；这是世界探索，不是与卡片人物单独聊天。
2. 单主角直接使用默认人物；多角色只出现一个选角界面。选角界面展示故事钩子、当前选择的肖像与处境，不用同一世界封面冒充每个人。
3. 确认角色后，有已配置的角色前情才展示；前情仅限角色可知事实，隐藏选角列表，提供“返回选角”与“进入当前场景”。无前情不增加空步骤。
4. 进入该角色当时所在地点。不同角色可以位于不同地点；不是人人都进入同一张封面里的房间。
5. 文字探索呈现场景及行动；有已接入开场视频的单主角播放后，同画面显示行动选择。没有角色专属视频的多角色不能把统一视频当作已制作的专属前情。

## 已有体验

- 返回首页保留已有存档，不直接跳回新建选角页。
- 在体验中“切换视角 · 时间不变”：继承同一存档的世界事实、时刻和进度，展示所换角色当时的位置与认知，不重播初始前情。
- 明确新建体验才重新选择起点；不把视角切换称为重新开始。
- 文字和视频进度目前分开保存；从视频“改用图文”不代表完成同一存档跨媒介无损转换，这仍须后续独立完善。

## 本轮边界

已合并非视频多角色的两套选角布局；不修改世界剧情事实或用户已有存档。视频界面全视口、选择面板浮在末帧下沿，保留原生播放控件。没有新生成视频、没有成片抽帧；布局通过不代表开场内容已变好。
