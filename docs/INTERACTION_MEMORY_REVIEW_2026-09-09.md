# 连续互动实测与记忆修复

## 本轮改动

- 世界探索、独立角色聊天把实际可见对白与说话人一起写进续接上下文；不只保存旁白。非当前体验者可见的台词不进入其记忆文本。
- 保存各 NPC 相对于入场时的关系变化，不再只保留一个全局关系分数。旧存档缺字段按无记录处理；单轮变化限制为 -10～10，累计 -100～100。分数不是自动恋爱、信任或秘密授权。
- 世界 Agent 按行动的信息量组织正文，普通问话不强制凑 350～650 字，明确要求不重复正文与对白。提示改进不等于模型每轮都遵守。
- 增加四项确定性回归测试，以及显式开启才运行的真实文字评估脚本；默认不调用模型，无媒体生成、私人存档或数据库写入。

## 真实模型检查

使用公开内置故事的副本和虚构测试身份，不使用真实用户资料。这里的“恢复”是序列化再读回，不是跨设备云存档、真实双账号或浏览器端到端验收。

### 许岚作为新增探索者

- 适配请求拒绝现实世界读心，允许基于可见线索且可能误判的观察。
- 原角色保留，新人停在门外与顾言舟、苏晚逐步接触，没有替换身份或获得初始秘密。
- 尝试读心被拒绝，未写入秘密或完成任务；首次接触没有直接结束世界。
- 续接请求最初超时。修复后复用前面成功结果，只补发失败请求；得到有效响应，姓名、所在位置、能力及关系变化保留。
- **人工质量仍未完全通过**：续接回答仍重复自我介绍，正文与对白仍有重复；整个样本未走完后续独立探索目标。不能用自动检查零报错替代体验质量验收。

## 媒体健康检查口径更正

同一正式地址 `/api/media`：不带账户范围请求头得到 503；按网页访客实际请求带 `x-xgen-account: guest` 得到 200、`configured: true`。此前的无请求头检查不能证明媒体存储或模型故障。本轮未调用媒体生成接口，配置可用也不等于所有模型已实测。
