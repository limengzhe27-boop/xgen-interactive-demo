# 首屏开场制作 · 2026-09-11

本批只制作现有世界的开场，不改写世界事实。用户要求原生声音，并明确跳过抽帧与成片画面检查。计划通过 native-direction 结构预检不代表生成质量通过。

## 公寓 · beauties-native-v1

世界：`surrounded-by-beauties`。新租客出电梯，咖啡泼箱、试菜被挡、误拿样机依次发生。15秒，三个5秒动作节拍；三句现场对白，不使用旁白或后期配音。停在玩家尚未解释身份、尚未答应任何工作与关系的位置。

风险：三个角色和道具可能被模型合并，不能用“有音轨”代替台词与表演质量判断。此次按要求不抽帧、不做实际观看验收。

## 桃花源 · peach-native-v1

世界：`peach-source`。渔人挤出山口、村老走近拦问、织者起身，最后村老问外面是否仍是秦朝。15秒，玩家未回答朝代，未进入村舍。保持既有文学改编设定，不添加恐怖袭击或秘密答案。

风险：模型可能将通过山口简化成风景运镜；导演层明确袖口碰壁、枝条拂开、村老走近和织者起身。

## 执行与接线

- 每部 `plan.json` 是故事事实、交接与原生台词；`direction.json` 是动作、走位、镜头和现场声音。
- `scripts/generate-home-openings.mjs` 使用现有公司网关模型名称 `doubao-seedance-2-5-260628`，15秒720p，`generate_audio=true`。该名称是网关标识，不代表已核实厂商版本映射。
- submit 先保存锁；超时仅 collect 原任务，不自动新买。运行记录在忽略目录 `work/<id>/`，不提交凭据或服务端任务记录。
- 只有实际返回有音轨文件才可绑定首页。保留原文件，无后期配音；音轨存在不证明台词正确或画面合格。
- 首页绑定 `worldPrologue` 后，单主角沿用 VideoExplorer，结束后选择行动或输入，后续调用既有 FAL MiniMax H3 Max 图生视频链路。没有因此声称实际续片验收已完成。
- 桃花源提交被权限审查阻止，等待用户明确授权向 Yibu/Seedance 发送剧情提示词并产生费用，不绕过。
