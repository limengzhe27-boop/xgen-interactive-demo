# 2026-09-06 个人 Agent 推荐与进入

## 交付边界

- 个人 Agent 可打开真实世界的身份选择，不自动选择角色、不自动创建新游戏、不在私聊里假装进入剧情。
- 明确的序号选择和完整标题命令由本地解析器执行，不再调用模型；自然语言选择可由 DeepSeek 返回 `open-world` 指令。
- 服务端检查操作类型及世界 ID；否定、介绍、比较和询问不执行模型误返回的跳转指令。客户端执行前仍检查当前目录和可用角色。
- 最新推荐顺序随账号本机资料保存。普通聊天不清掉列表；失效世界保留编号，不能把后面的推荐移到前面。旧资料没有推荐上下文时要求明确选择，不根据历史纯文字猜测。
- 推荐回复自动附上与卡片一致的编号。只有打开身份页后才写入操作结果；离开个人 Agent 页后到达的模型回应不触发跳转。
- 没有新增全局自主 Agent、个人身份、云同步、世界公开发布或生图调用。

## 验证

- 72 项自动测试通过，生产构建通过。新增模块与相关组件、接口定向 lint 通过；原有 page.tsx Hook 告警不作为本轮无关重构范围。
- Tabbit 使用合成账号与拦截回复：推荐两本→第一个打开苏晚身份页；刷新→第二个打开林照身份页；选择不增加模型请求；含糊选择和否定不跳转；模型指令触发真实页面切换；离开页面后的迟到指令不抢回页面。
- 合成账号 A/B 推荐列表隔离，切回 A 保留顺序；390px 手机输入“我选第一个”可打开正确身份入口。
- 本地真实 DeepSeek 两次调用，仅发送用户已允许的《契约到期，总裁不肯散场》原创虚构测试简介与合成对话，不发送个人记忆、真实存档或公司资料。推荐和自然语言 `open-world` 返回均为 200，世界 ID 正确。这是有限样本，不代表所有表达均能准确识别。
- 本轮不调用付费生图，明确选择已有推荐也不消耗文字模型调用。
