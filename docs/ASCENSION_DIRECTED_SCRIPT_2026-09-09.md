## 使用与检查边界

本地生成两类提示和完整声音安排：

```sh
node scripts/prepare-prologue.mjs docs/prologue-first-person.example.json --direction docs/prologue-first-person.direction.json
```

这不会联网或扣费。检查只覆盖时间、字段、引用与节拍覆盖；不证明表演自然或不水。动作仍不成立时需要改首帧、切点或镜头长度，而不是无限追加形容词。末段若仍显重复应缩短，不必凑28秒。当前网站旧视频未替换，所有新视频测试继续等待用户指令。
