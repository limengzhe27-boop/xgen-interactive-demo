# 事件收束与可选任务（2026-09-21）

## 产品变更

- 移除“预期走向 / 其他走向”独立编辑框。旧草稿文字保留为只读历史构思，不自动变成节点或结局；新模型提案不能重新填入这些字段。
- 发展与分支统一在故事画布；已有 eventIntent、trigger、possibilities 继续区分关键事件和条件性可能。
- 每个事件增加可选 closingCondition。留空合法，末尾节点不意味着结局，不要求每条路线收束。
- tasks=[] 合法；手动生成不再从分幕补任务，AI 生成也不将未授权任务写回空任务草稿。发布允许无任务、无结局。

## 运行与兼容

closingCondition 随画布建议、保存、发布白名单及恢复保留。世界运行时将其作为阶段收束条件：同时需要 `story-event:<nodeId>:occurred` 和收束条件原文作为实际提交事实。只有条件文本、其他分支的事件标签、到达图末尾均不能满足检查；已展示的收束不会重复触发，仍可继续。

这不是完整的确定性剧情引擎：事件是否真正发生仍需模型依据叙事与存档提交证据，代码检查标签齐备不能证明叙事语义绝对正确。不得声称完整 DAG 运行与长期认知隔离已经完成。

既有发布世界的 endingConditions 保留，不从旧方向文字新建条件。本次不删除旧作品内容、不自动发布用户作品、不生成收费媒体。
