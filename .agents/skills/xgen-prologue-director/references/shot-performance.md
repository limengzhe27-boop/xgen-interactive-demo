# 表演层：让模型有具体动作可演，而不是增加形容词

## 使用范围

已有世界前情、为其制作分镜或修复“站桩/水时长”提示时，故事层之后必须补这一层。调度、机位和小动作是拍摄提案；新的身份、道具、能力、动机和剧情结果不是“导演细化”，必须回到已确认设定。来源与选择取舍见项目 `docs/VIDEO_SKILL_RESEARCH_2026-09-09.md`。

“低头看剑，然后抬眼，官员举牌”仍是故事梗概。需要说明：握剑的力怎样改变，因哪句声音停住，视线从何处找到说话者，官员由哪只手/哪个高度举牌，举到哪里停，下一镜尚未发生什么。只给气氛、景别和运镜术语不算表演稿。

## 一镜的三个交付物

1. **首帧与空间卡**：起点就容纳将发生的动作。标演员相对位置/朝向、持物归属、前后地标、实体光源；首帧哪些必须可见、哪些只能由参考图补足。不是把第三人称封面直接塞给第一人称片段。
2. **表演节拍表**：按实际动作非均匀分时，写身体/道具动作、镜头响应、观众看到的变化。通常2–5拍足够，也允许一次完整长动作；不强迫每秒换镜。时间是剪辑目标，不是承诺模型逐帧服从。
3. **尾帧与续接卡**：位置、目光、手中物件、受力/关系状态、尚未发生的动作。下一镜从真实合格尾态接，不把计划尾态当成已经生成的画面。

填写机器格式时，每镜用 `layout / firstFrame / camera / beats / lastFrame / avoid / referenceRequirements / risk / sound`。每个beat用本镜相对秒 `start/end`，以及 `blocking/camera/change`。对白沿用故事层全片时间；环境声写本镜相对时间，编译时换算，不把音效和人物台词混成一个长字符串。

## 如何细化，不如何灌水

- 从人物目的开始选主动作。动作可以包含起势、接触、受力、反应、停住，但不是往同一段里添五件无关的事。
- 起势：什么声音、目光、物件变化触发行动？不让演员无缘无故持续抖动。
- 过程：谁动、向哪里、到哪里结束；对方保持什么或如何回应？微小动作必须有可见尺度，远景里不能要求看清指节。
- 镜头：为了看清哪一次变化而倾转/平移/切镜，终点是什么？先写演员调度，再写摄影响应。不要让摄像机前推冒充人物走近。
- 反馈：力量传到衣料、手腕或链时，哪个先动、哪个后动？不是写“真实物理”四个字。未发生接触不凭空出现声音或损伤。
- 停顿：等待回应、消化一句话或看清结果可保留。静止不一定是水；重复同一举牌、凝视、推镜而没有变化才可疑。问“删掉这段会少什么”，不是要求每一帧都有爆炸。
- 连续性：左右手不换，道具不瞬移，链从哪里来就通向哪里。机位变化不意味着实体光源换边；相邻镜空间不能被重新抽签。
- 第一人称：摄影机是体验者的眼睛，手部运动和视线有身体动机。不得同时外拍自己背影又声称主观视角。
- 给模型的约束只选当前风险，不搬一整页所有可能错误。数值用于表达意图，不能把未验证的角度、距离、时间精度当能力保证。

## 导演稿不等于模型输入

编译器 `lib/prologue-direction.ts` 输出两种视觉提示，不自动提交：

- **文生视频** `textToVideoPrompt`：包含场景、角色外形与相对位置，再叙述连续动作。适用于经核实支持该输入的模型；不是当前已绑定提供商。
- **图生视频** `imageToVideoMotionPrompt`：首帧已经锁住外观时，主要写变化、运镜和尾态，不重复一整份角色档案。必须先核对实际首帧符合 `referenceRequirements`；没有适配图时不能声称可直接提交。
- `directorTimeline`保留精确导演分时；模型运动提示按有序动作组织。只有核实模型支持时间戳分镜才把时间段当相应输入，不能虚构接口字段。
- 内部人物ID、文件名、审查状态不写进模型视觉正文；精确文字另列后期叠加。
- 声音必需：对白原句、说话人、不同声线/语气沿用主计划；环境声与接触声逐拍对应。后期方案要真的混音并听检后才算有声成片。原生音频是否可用须单独核实。

## 交付与风险处理

正式交付必须同时给人读导演表、可复制的模型提示、声音安排，不只交字段清单。逐镜标最可能失败的动作。模型不擅长的关键动作不能直接删掉，先设计可理解的切点；也不能用闪白遮住关键接触再宣称拍到了。

本地检查可发现漏镜、漏字段、错序、时间断档/重叠、越界、未覆盖尾帧；不能判断自然表演、真正空间一致性或语义上是否水。没有实际试拍就写“待验证”，不写质量分数、必爆或保证不水。
