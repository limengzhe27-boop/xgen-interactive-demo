# 成片验收

输入：已确认前情、分镜 plan、实际可访问的视频/帧与音轨。先区分“计划检查”和“成片检查”；没有实际视频就停止在计划结论，不伪造时间戳证据。

1. 先运行项目 `scripts/prepare-prologue.mjs` 检查分镜。机器只校验结构，不理解演员表演。
2. 使用当前可用的媒体/浏览器工具实际看成片，抽查每镜开始、关键动作、结尾；关键关系动作不能只看单帧。媒体不可访问则报告未验收，勿下载绕过访问限制。
3. 不看创作者解释，尝试复述：谁和谁、什么关系、在哪里、做了什么、为什么突然紧张、下一步还没做什么。只能靠大段字幕解释的动作视为证据不足。
4. 核对锁定人物、衣着、道具、位置、时间顺序和动作接续；先验上段，才生成依赖它尾帧的下段。音画冲突优先修，不用音乐掩盖。
5. 检查末帧与互动现场一致：视频没替玩家回复/开门/选择阵营；角色与自带身份仍有合理入口；选择控件在首屏，视频保留，不跳到新页面。

## 有证据的判定

用“问题代码—时间范围—实际看见—应该看见—最小修法”记录。

- STORY：关键事件没有发生，或多拍了未发生的未来。
- IDENTITY：人物身份/关系看不懂，演员漂移。
- CAUSALITY：动作和后果不相连，物件凭空变化。
- FILLER：删掉镜头不影响任何事实、压力或接续，只是在凑秒数。
- HANDOFF：最后选择已替玩家做掉，或视频现场与游戏开场不一致。
- AUDIO：对白归属错、音轨缺失却标有声、关键信息听不清。

任何关键项失败不算可上线。标签或金额错可后期修，没拍到关键行动不能靠补字幕蒙混过关。优先保留合格镜头，只重做失败段；报价、剩余次数和用户授权不明确时不追加付费。失败/不确定任务先查询，不自动重提。

输出短结论与证据，不宣称必爆或“保证质量”。本轮自己写自己看须标自审；未使用独立人员/上下文不可声称独立验收。
