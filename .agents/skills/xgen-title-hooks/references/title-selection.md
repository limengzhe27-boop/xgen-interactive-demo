# 互动世界的命名选择（2026-09-10）

## 资料取舍

用户提供的第三方AI总结是参考提案，不是验证过的增长规律。吸收具体关系/动作/物件、多角度候选、长短标题分工；不沿用「必出上百个候选」「必须设计三部续作」「人物必须惨、结果必须爽」。三秒/五秒/十分制只是自评方法，不能当实测点击数据。亲密、恐怖、幽默等强度随用户题材，不能把全部世界改成复仇文。

- [Character.AI Greeting and Voice](https://support.character.ai/hc/en-us/articles/50609011294235-4-Greeting-and-Voice-%EF%BC%90-%E3%83%8E)：发现资料争取点击，Greeting 定义实际对话节奏；推论是标题承诺必须被开场兑现，卡片邀请不能冒充既往消息。
- [Character.AI Creator Insights](https://support.character.ai/hc/en-us/articles/51616603738395-Creator-Insights)：观察角色的 greeting、scenario、tags 等差异；不要把效果归因于标题单一变量。
- [ReelShort 题材目录](https://www.reelshort.com/movie-genres/all-movies)：广义题材与关系/反转类细标签并存。借鉴「关系+困境」的可理解性，不复制片名，不把所有细标签升为导航。
- [AI Dungeon 场景说明](https://help.aidungeon.com/faq/what-are-scenarios)：场景可附标签帮助发现。平台固定发现入口，作者标签与体验视角分开。

本轮仅研究公开网页，不声称体验了产品登录后界面，也未找到可证实的红果官方起名Skill。

## 先用证据决定可写什么

提取公开开场、可选身份、当前阻力、可回应动作、不能公开的未来答案。不要拿角色私密知识或未达成结局做宣传事实。若原题比剧本夸张，先收回承诺，不为保标题擅改剧本。

| 角度 | 适用 | 要排除 |
| --- | --- | --- |
| 身份反差 | 固定第一人称/异常职业体验 | 多角色世界强行指定所有用户的身份 |
| 时间+事件 | 已有期限或现场变故 | 凭空加「只剩十秒」 |
| 关系+阻力 | 恋爱、家族、知己交易 | 陌生家族/人名堆叠、伪造访客婚恋关系 |
| 物件+疑问 | 契牌、借据、冲突证据 | 泄露物件背后最终真相 |
| 任务/挑战 | 阅读、调查、求生 | 假问题与强迫二选一、暗示必胜 |
| 口语/称呼 | 有鲜明角色口吻与整活 | 每张都喊「完蛋」「全家跪了」 |
| 短意象名 | 图像和副句已清楚交代处境 | 单独出现抽象意象，让用户猜玩法 |

默认比较三种角度即可，用户要候选时才展开。结果型仅能写已经发生的开场，不写用户尚未做出的报复/恋爱/胜利。选三项软标准：一眼理解、形成具体好奇、与同屏其他卡片不重复；剧情不符/身份误导是硬淘汰，不用平均分救回。

## 本轮审校样例

- 蜘蛛：旧卡只说桌底的家 → 「我成了桌底蜘蛛，清洁刷正逼近我的卵」。公开开场已有清洁刷、卵囊，展示可救援/避让的眼下压力。
- 李白：移除贵妃与传世名篇的未兑现承诺 → 「李白的酒局：写一首诗，还是卖一次沉默？」公开开场诗笺、借据、来使索诗，结局未写死。
- 桃花源：不把「不知汉魏晋」简化成村民断言外界仍是秦朝 → 「误入桃花源，第一句话该告诉他们什么？」对应老人问今是何世，保留阅读判断。
- 遗嘱：由抽象的前夜 → 「遗嘱还没宣读，谁已经坐不住了？」对应提前签管理意向书的压力，不透露具体份额。
- 草船：借二十条船而不告诉周瑜，来自当前请求；不宣布已经借箭成功。
- 校报：三份材料互相冲突，邀请核查而不是预定谁撒谎。
- 月球：同事的质量判断是待验证说法，标题明确归属于同事，不把科学误解当事实。

修改保留ID、角色姓名和存档。首页短名可用展示层覆盖，但详情显示同一短名或明确原名；避免用户点开误以为换了一部作品。已有图片沿用不等于新封面完成。记录修改依据，后续比较点击、首次有效回复及标题不符反馈，不能只看点击。
