# 角色发现卡：情景—姓名—钩子

依据用户2026-09-10提供并要求采纳的文案方案整理。目标是让访客想和角色聊一句，不是完整人物档案、剧情摘要或玩家身份选择。以下示例是原创宣传邀请，不是原作引文或已发送的消息。

## 三层分工

- 顶部世界情景：公开的事件、关系局面或异常，优先一行、最多两行。不写长背景，不与底部重复完整句子。
- 中部姓名：只显示角色名，视觉最醒目。不要追加年龄、性别、职业、成年标签或广告副标题。
- 底部钩子：一个最强的对话动机，按下文表达来源选择。优先8—20字，最多两行；不是硬截断到20字。

先判断姓名与顶部是否已足够识别人物；不足时只补一个有用的身份线索。身份、年龄、职业只有自身构成剧情反差或识别需要时才融入钩子，不为档案完整而罗列。原身份数据不删除，仍供搜索与剧情使用。

## 从证据写邀请

先看公开开场、角色公开性格和已知关系，再写短句。不能借秘密制造点击、承诺未发生的结局、给陌生访客强加配偶身份，不能把别的AI示例当剧本事实。角色口吻可表现邀请、试探、幽默、亲近，不必人人威胁或交易。

例如当前第九回改编的吴月娘可用「新来的第五房，该怎样接这个礼？」；不能照搬「他给你的情话，我这里还有两份」，因为没有这项证据。李白可用「这杯酒，敬知己还是买我的沉默？」；不能声称已经写出传世名篇。

## 人称与表达来源是两个维度

语法人称回答句子指向谁：第一人称（我/我们）、第二人称（你）、第三人称（他/她/姓名）。表达来源回答谁以何种功能表达：

| 来源 | 判断及使用条件 |
| --- | --- |
| 角色台词 | 明确朝访客说，能自然接话；可用我或你，不必是问句。不是泛泛寒暄。 |
| 互动旁白 | 外部叙述用你邀请参与，不预设用户姓名、性别、固定角色、关系、持有道具或已经作出的决定。 |
| 角色心里话 | 未说出口的情绪、欲望或内在矛盾，不冒充给用户的指令。只能用已公开或作者明确批准用于宣传的信息，不直接读取私密答案。 |
| 系统旁白 | 外部描述角色此刻异常或未决处境，要有事件，不是静态档案。 |
| 角色自述 | 角色讲自己的经历或处境；只有身份本身构成反差时优先使用，避免重复顶部。 |

默认尝试台词→互动旁白→心里话→系统旁白→自述，但以贴合剧情和对话动机为准，不机械套顺序。每张仅保留一个钩子，不把五类并排展示。

「你也来找西门庆？」是第二人称台词；「她刚进西门府，先要向大娘子行礼」是第三人称旁白。「我不能让她看见这把钥匙」仅从文字无法判断是台词还是心里话，必须知道创作者设定的表达语境，并先核验钥匙是否存在。不能凭出现“我”或引号判断来源。

一句话可同时有我和你，也可能省略主语。编辑审校时标注涉及的人称或说明省略，不强塞三个单选值。角色台词是宣传拟写，不因此成为已发送的第一条消息；心里话被宣传展示，也不自动成为所有NPC的知识。

## 生成判断与可选数据方案

先确认顶部已说什么及姓名识别度，再找一个可公开的冲突/情绪；决定由角色还是旁白表达，然后选择人称。检查第二人称是否替用户安排行动、与顶部是否重复、能接什么话、是否只有一个悬念。泛泛“你好”“你能帮我什么”“想聊什么”不算专属钩子。

后续可记录 scene_title、character_name、hook_text、hook_person、hook_source、hook_intent、identity_included。前两项优先引用已有世界/角色数据避免双份漂移；hook_person需要兼容混合或省略，hook_source为上述五类，hook_intent用于作者审校而非卡片展示。这是待实现的数据方案，不是目前API已支持字段。来源标签与人称不必显示给体验者，不能擅自在现有JSON契约新增字段。

## 展示与作者控制（实现边界）

卡片宣传、角色身份、真实开场白是不同内容；宣传不能写入剧情历史。作者的已确认文案优先，Agent只建议，不擅改姓名或身份来曲线写宣传。当前已提供独立 cardHook 文本字段，创作者在角色编辑区修改，Agent在 proposal.characters[].cardHook 提议，采纳后保存；世界生成与发布使用 world.characters[].cardHook。最多60字、无换行，推荐8—20字。已填写或明确清空值优先于自动建议；人称/来源等分析字段仍是后续方案，不擅自新增到API。

手机也要能看到钩子；顶部与底部各两行截断，长姓名不能被档案挤掉。未审校内容不使用万能模板伪装成精修；缺少钩子时暂不显示身份档案作为兜底。保持首页名单、混排、搜索与点击目标不变。

## 自检

陌生用户知道什么情景、面对谁、能问哪一句吗？顶部与底部各做一件事吗？短句有公开依据吗？是否泄露答案或假装角色已经说过？检查桌面和手机样式约束、真实角色ID、搜索保留，以及未改世界状态。
